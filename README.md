# CalcVerse

CalcVerse is a web-based calculator platform built with Django.

## Features

- Basic Calculators
- Scientific Calculators
- Unit Converter
- Random Number Generator
- Random Picker
- Roman Numeral Converter
- Word Counter
- Text Case Converter
- Coin Toss
- Responsive Design

## Built With

- Python
- Django
- HTML
- CSS
- JavaScript
